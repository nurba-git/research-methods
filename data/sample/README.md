# Sample data

`student_results.csv` holds ten **synthetic** rows used only as a smoke test for
`src/benchmark.py` (Task 2 quickstart). Each row is one randomized student:

| Column | Meaning | Unit |
|---|---|---|
| `student_id` | Pseudonymous ID | – |
| `group` | `traditional` (baseline) or `adaptive` (AI-adaptive platform) | – |
| `pretest_score` | Score on the common pre-test | points, 0–100 |
| `posttest_score` | Score on the common post-test | points, 0–100 |
| `learning_time_min` | Mean time on task per weekly session | minutes |

These rows are not real student observations and must not be cited as evidence.
